# Motion credits

The local project gallery draws on the circular layout, liquid connections and inertial navigation of [Misty-Forest-Portfolio](https://github.com/yizhixuanzhu/Misty-Forest-Portfolio).

## Derivative works

Misty-Forest-Portfolio derives from [MegD1/Ice-works-showcase](https://github.com/MegD1/Ice-works-showcase), which derives from Yousuf Soomro’s [Viscose Carousel](https://github.com/Yousuf-developer/Viscose-carousel).

The round-box, tapered honey bridge and smooth-union distance helpers in `src/LiquidGallery.tsx` are adapted from the reference shader. The React component, compact WebGL renderer, image atlas, local interaction handling and responsive layout were written for this portfolio. The applicable MIT notices are retained in [the bundled license](public/credits/misty-forest-LICENSE.txt).
