# Motion credits

The local project gallery draws on the circular layout, liquid connections and inertial navigation of [Misty-Forest-Portfolio](https://github.com/yizhixuanzhu/Misty-Forest-Portfolio).

## Derivative works

Misty-Forest-Portfolio derives from [MegD1/Ice-works-showcase](https://github.com/MegD1/Ice-works-showcase), which derives from Yousuf Soomro’s [Viscose Carousel](https://github.com/Yousuf-developer/Viscose-carousel).

The round-box, tapered honey bridge and smooth-union distance helpers in `src/LiquidGallery.tsx` are adapted from the reference shader. The React component, compact WebGL renderer, image atlas, local interaction handling and responsive layout were written for this portfolio. The applicable MIT notices are retained in [the bundled license](public/credits/misty-forest-LICENSE.txt).

## Character ocean

The work explorer integrates the user-supplied local `character-ocean` project by jiezi1234. Its animation files in `src/ocean/` originate from stackedlol/ascii-sharks, as documented in the supplied [license scope](public/credits/character-ocean/LICENSE.md) and [third-party notices](public/credits/character-ocean/THIRD_PARTY_NOTICES.md). Those files retain their original attribution; the frontend MIT license does not relicense the upstream animation.

This portfolio adds the React lifecycle, lazy loading, real project search, random navigation, and tab-visibility pause handling. The original portfolio gallery and photo interaction remain separate. Geist Mono is included under its [SIL OFL license](public/credits/character-ocean/OFL.txt). No Noto Sans font is included.
